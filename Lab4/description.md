# Теоретическая преамбула

k = (e, n) - открытый ключ
l = (d, n) - закрытый ключ

n - известное, очень большое, составное, вида n = p*q, где p и q - простые
e * d = 1 mod phi (n)

e in {1, n-1}

C = E_k(M) = M^e mod n - шифровани
M = D_l(C) = C^d mod n - дешифрование

phi(n) = (p-1)(q-1)

# Интерфейс программы

1. Проверка математики
2. Выполнение процедуры шифрования и дешифрования со значениями p и d из варианта
3. Выход

## Проверка математики

1) Расширенный алгоритм Евклида из ЛР2
2) Быстрое возведение в степень по заданному модулю (Бинарный алгоритм возведения в степень)
- Нахождение обратного
- Вход a,n,m. Выход: a^n(mod m)

## Выполнение процедуры шифрования и дешифрования со значениями p и d из варианта

1) Множество ключей (k,l) (мощность множителей не менее 3 шт)
- Вход p, q
- Создать не менее трех пар ключей { {(e,n), (d,n)}, {(e,n), (d,n)}, {(e,n), (d,n)} } - генератором случайных значений, пары желательно как то пронумеровать

2) Демонстрация шифрования
- Вход: открытый текст (русские буквы + пробел), укажите ключи
- Переводим символы в цифры соответствии с таблицей
- Открытый текст целиком разбиваем на блоки с нефиксированным размером. Размер блока M увеличиваем пока длина M < n. Первая цифра в блоке не должна быть 0.
- Отдаем число M в функцию шифрования. Надо завести массив с зашифрованными блоками.

3) Демонстрация дешифрования 
- Поэлементно расшифровать массив
