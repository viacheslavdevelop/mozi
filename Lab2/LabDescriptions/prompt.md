Выполни работу из файла Lab.md на языке python.

Для каждой функции предусмотреть ввод параметров из консоли и из файла (выбор 1 - из консоли, 2 - из файла). Также предусмотреть ситуации с пустым и некоректным вводом, программа ни в коем случае не должна ложиться.

Код не должен содержать комментариев, быть удобочитаемым.

Как должен выглядеть интерфейс (в консоли):

## Главный интерфейс
1) Проверка "математики"
2) Выполнение варианта 
3) Выход

## Интерфейс Проверка "математики"
1) Расширенный алгоритм Евклида. Вход: a,b; выход: НОД(a,b)
2) Вычисление a^-1(mod m). Вход: a,m; Выход: a^-1(mod m) если такое есть.
3) Решение сравнения ax = b (mod m). Вход: a,b,m. Выход: решений нет, решение одно, решений несколько.
4) Решение сравнения {(a*x + y) mod m == b (c*x + y);mod m == d. Вход: переменные из уравнения Выход: решений нет, решение одно, решений 
5) Выполнение частотного анализа шифр-текста и определение двух самых часто встречающихся букв. Вход выход определи сам на основе текста лабораторной работы
6) Выдвижение предположений о том, какие буквы открытого текста соответствуют выявленной паре самых часто встречающихся символов шифр-текста. Вход выход определи сам на основе текста лабораторной работы
7) Шифрование при помощи Афинного Шифра. Вход: текст, ключ; Выход: зашифрованное сообщение
8) Расшифровка с известным ключом. Вход: шифр, ключ; Выход: расшифрованное сообщение
9) Выход

## Интерфейс Выполнение варианта

Перечисленные действия просто выполнить по подрядку

1) Загрузить с файла или считать с консоли зашифрованное сообщение
2) Перебор ключей. Программа поочередно выводит ключи (подходящие), пользователь сам смотрит какой шифр подходит. Если скип, то нажимает одну клавишу, если подходит, то другую. Результат сохраняется в файл.

Можно еще попробовать не в тупую перебрать, а при помощи таблицы частот определить самые часто встречающиеся символы и как то по ним приблизится к ответу.





В данном коде необходимо внести следующие правки:

Из меню "Проверка математики" необходимо убрать менюшки 5 - 8.

Меню "Выполнение варианта" нужно полностью переделать. 

Вход: шифр - текст
Далее идет запуск текста на частотную обработку. Например: p(а) = 3/63, p(ы) = 15/63... 
Сортируем полученный по убыванию частоты. Выводим две самые встречаемы буквы и их частоты.

Выдвигаем гипотезы по частоте встречаемых букв. Предполагаю, что символы которые в шифровке оказались самыми частыми, они и есть самые частые в русском тексте.

Берем таблицу вероятностей каждой буквы (формат буква частота, отсортировано по частоте). Составляем всевозможные пары букв и для каждой пары считаем вероятности. Сортируем пары по вероятности и таким образом перебираем гипотезы.

Перебираем по следующей логике. 

Сопоставляем индекс букв и составляем систему и решаем (как в п 4).

Если получилось, то есть вариант ключа (или несколько). Попробовать расшифровать. Если подошел (пользователь сам смотрит, подошел ли ключ и нажимет клавиши), то конец. Если нет, то переходим к новой гипотезе (новая пара). Если ключей (решений системы) несколько, то перебираем все.

Если система не разрешима сразу, то гипотеза не состоятельна. Значит переходим к новой гипотезе (новая пара).
