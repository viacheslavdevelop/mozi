1) Проверка алгоритмов

1. Расширенный алгоритм евклида (Вход: a,b Выход: НОД, коэффициенты безу)
2. Вычисление обратного элемента (Вход: a,m, Выход: не существует, обратный элемент). Коэфициенты безу берутся из алгоритма евклида 
3. Решение сравнения ax = b (mod m) (Вход: a,b,m, Выход: Решений нет если d (НОД(a,m)) не делитель числа b, решение одно, d штук (d | b))
4. Как и в третьем

2) Выполнение вариант

Вход: шифр - текст
Запуск текста на частотную обработку. Например: p(а) = 3/63, p(ы) = 15/63... 
Сортируем полученный по убыванию частоты. Выводим две самые встречаемы буквы.

Выдвигаем гипотезы по частоте встречаемых букв. Предполагаю, что символы которые в шифровке оказались самыми частыми, они и есть самые частые в русском тексте.

Перебираем по следующей логике. 

Сопоставляем индекс букв и составляем систему и решаем (как в п 4).

Если получилось, то есть вариант ключа (или несколько). Попробовать расшифровать. Если подошел (пользователь сам смотрит, подошел ли ключ), то конец. Если нет, то переходим к новой гипотезе. Если ключей несколько, то перебираем все.

Если система не разрешима, то гипотеза не состоятельна. Значит переходим к новой гипотезе. 

Для новой гипотезы:

Берем таблицу вероятностей каждой буквы. Составляем всевозможные пары букв и для каждой пары считаем вероятности. Сортируем пары по вероятности и таким образом перебираем гипотезы.
