1) Метод пробного деления должен выдавать не просто два первых множителя, а разложить число полностью на простые множители. В программе все должно также корректно отрабатывать, все edge кейсы должны быть покрыты, ошибок при выполнении быть не должно.
2) Алгоритм пробного деления должен проходить по другой схеме. Должны перебираться только простые числа, тройками. Проверяется у каждой тройки (умножаются три простых числа для ускорения) НОД, если он 1, то дальше, если другое число то проверяется как-то циклом какие там точно делители.
